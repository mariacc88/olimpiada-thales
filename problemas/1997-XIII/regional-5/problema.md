## Enunciado

El papel que estás usando tiene un formato DIN A-4. Este formato se diseñó para que si se duplica (o se reduce a la mitad) con una fotocopiadora, la proporción entre el ancho y el alto no varíe. Así, el A-3 tiene el doble de superficie que el A-4, el A-2 el doble que el A-3, el A-1 el doble que el A-2 y, finalmente, el A-0, que es el doble del A-1, tiene una superficie de 1 m². ¿Podrías deducir las dimensiones en milímetros (sin decimales) de un formato DIN A-4?
